# Ticket to Ride Classic Score

Простой веб-калькулятор финальных очков для классической версии Ticket to Ride.

## Что считает

- очки за построенные маршруты по базовой таблице;
- очки за выполненные destination tickets;
- штраф за невыполненные destination tickets;
- бонус `+10` за `longest continuous path`.

## Что не считает автоматически

- кто именно выиграл `longest path` между несколькими игроками;
- очки других игроков;
- правила расширений и других редакций игры.

Бонус `longest path` включается вручную переключателем для конкретного игрока.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Структура

- `src/app` — шаблон и логика интерфейса;
- `src/game` — правила подсчета и начальное состояние;
- `src/styles` — стили приложения.
